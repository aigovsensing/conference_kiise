# KIISE 우수 SW 국제학술대회 대시보드 (2014 ~ 2024)

한국정보과학회(KIISE)가 선정·발표한 **우수 SW 국제학술대회 목록**을 한눈에 볼 수 있는
정적 웹 대시보드입니다. **2014·2016·2018·2020·2024년** 목록을 연도별로 열람할 수 있으며,
S/A 등급 구성, 대분야(AI·CS)·소분야(16개)별 분포를 시각화하고,
전체 학회 목록을 검색·필터·정렬할 수 있습니다. (기본 화면은 최신 연도)

> **등급 의미** — **S 등급 = 최우수**, **A 등급 = 우수** 국제학술대회를 뜻합니다.
> 여기에 KIISE가 지정하지 않은 일반 해외 학회를 **기타**(참고용)로 함께 보여 주어,
> 대시보드는 **최우수(S) · 우수(A) · 기타** 3개 분류로 구성됩니다.

## 🔗 참고 사이트 (데이터 출처)

- **KIISE 우수 국제학술대회 목록 공식 안내**:
  <https://www.kiise.or.kr/academy/main/getContent.fa?content_no=86&MENU_ID=130500>

원본 데이터는 위 KIISE 공식 안내 페이지 및 연도별 PDF 목록을 정리한 것으로,
`data/excellent_sw_conferences_<연도>.csv` (2014·2016·2018·2020·2024) 파일에 담겨 있습니다.

> **연도별 데이터 안내** — 2014~2020년 원본 PDF에는 대분야(AI/CS)·소분야 분류가 없어,
> 2024년 목록을 기준으로 학회 약칭을 매칭해 분류를 복원했습니다. 2024년 목록에 없는
> 과거 학회는 도메인 지식으로 분류했습니다. 등급(S/A)·학회 목록은 원본 PDF 그대로입니다.

## ✨ 주요 기능

- **요약 통계 타일** — 전체 학회 수, S/A 등급 수, 대분야·소분야 수
- **대분야별 등급 분포** — AI·CS 두 대분야를 S/A 등급으로 나눈 누적 막대 (**호버 툴팁**)
- **등급 구성 도넛** — 전체 학회의 S/A 등급 비율 (**세그먼트 호버 툴팁**)
- **소분야별 학회 수** — 16개 소분야를 대분야(AI/CS) 색상으로 구분한 가로 막대 (내림차순, **호버 툴팁**으로 S/A 내역 표시)
- **연도별 학회 논문 출판 현황** — 연도·연구 분야 필터, 총 논문 수·최다 학회·전년 대비
  요약 카드, 전체 흐름을 비교하는 히트맵과 선택 연도의 상위 10개 학회 가로 막대그래프
  ([DBLP](https://dblp.org/) 학회 스트림의 실제 등재 레코드 수를 매월 자동 갱신하며
  KIISE의 16개 소분야를 모두 지원). 분야 선택 시 요약 카드는 해당 분야만 집계하고,
  히트맵·상위 10개 그래프는 전체 비교를 유지하면서 선택 분야를 강조
- **섹션별 고유 주소** — 대시보드 서브 메뉴가 `#major-card`, `#publication-card` 같은
  주소를 사용하므로 원하는 그래프를 바로 열거나 공유 가능
- **화면별 고유 주소** — 대시보드·개최지별·달력·목록 화면도 각각 `#dashboard`,
  `#korea`, `#calendar`, `#list` 주소로 바로 열거나 공유 가능
- **모든 세부 메뉴 고유 주소** — 한국·일본 개최 현황(`#kr-country-KR`, `#kr-country-JP`),
  마감 캘린더·다가오는 마감(`#deadline-card`, `#upcoming-card`), 학회·삭제 목록
  (`#list-card`, `#deleted-card`)도 주소로 직접 접근 가능
- **🌏 개최지별(한국·일본) 학회 현황** — 개최 장소가 **한국 또는 일본**인 탑티어
  학회를 나라별·연도별로 정리 (학회명·제출마감일·개최지·학회 일정·공식 사이트).
  일본은 한국에서 비행기로 평균 2시간 내외라 가까워, 국내·근거리 개최 학회에
  논문을 제출하면 해외 출장비·이동 부담을 줄일 수 있습니다. ICML·ICLR·AAAI·
  NeurIPS·IJCAI·CVPR·ICCV·ECCV·ACL·EMNLP·NAACL·ICASSP·INTERSPEECH 등 **특별 관리
  대상 13개 학회**는 한국·일본 개최 시 **빨간색**으로 표기
- **학회 목록 표** — 약칭·학회명 검색, **연도**/대분야/등급/소분야 필터, 열 정렬
  - 기본 정렬은 **S 등급 우선**(그다음 번호순)
- **연도 지원** — 여러 연도 CSV를 자동 병합하고 연도 필터 제공 (아래 *데이터 갱신* 참고)
- **제외(삭제) 학회** — 목록에서 빠진 학회를 접이식으로 별도 표시
- **기타(참고용) 학회** — KIISE 비지정 일반 해외 학회·워크숍(`data/misc_sw_conferences_2024.csv`)을
  회색 "기타" 등급으로 표시. 요약 타일·등급 구성·대분야/소분야 차트, 목록(등급 필터 **기타**, 공식 사이트 🔗 링크),
  **달력**(논문 제출 마감 캘린더 · 다가오는 마감, 회색 점선 칩 + S/A/기타 분류 필터)에 반영.
  *이전 대비 변동*과 대시보드 *월별 학회 현황*은 KIISE 지정(S/A) 학회만 집계
- **라이트/다크 테마**, 반응형(모바일) 지원, 외부 라이브러리 의존성 없음

## 🔄 데이터 갱신 · 연도 추가

원본 CSV를 수정한 뒤 빌드 스크립트를 실행하면 대시보드가 읽는 `docs/assets/data.js`가
다시 생성됩니다.

```bash
python3 scripts/build_data.py
# → docs/assets/data.js 갱신
```

**기타(참고용) 학회 갱신**: `data/misc_sw_conferences_2024.csv` 에 행을 추가·수정한 뒤
`python3 scripts/build_data.py && python3 scripts/update_deadlines.py` 를 실행합니다.

| 컬럼 | 설명 |
|---|---|
| `번호` | `2024-M-001` 형식 (연도는 번호 → 파일명 순으로 추출) |
| `대분야`, `소분야` | KIISE 목록과 같은 코드 (AI/CS, ML·NLP·CV·Net·SE …) |
| `약칭`, `학회명`, `공식사이트` | 약칭은 KIISE 학회 약칭과 겹치지 않게 (예: `CVPR Workshops`) |
| `등급` | 항상 `기타` (대시보드 내부 코드 `M`) |
| `회차`, `초록마감`, `논문마감` | 직전 회차와 그 마감일(YYYY-MM-DD). 비워 두면 달력에 표시되지 않음 |
| `주기` | 개최 주기(년). 비우면 매년, 격년 학회는 `2` (예: ASRU, ICCV Workshops) |
| `비고` | 워크숍 소속 등 메모 |

마감일은 `update_deadlines.py` 가 KIISE 마감과 같은 방식으로 매년(또는 `주기`마다) 앞으로 투영해
`docs/assets/deadlines.js` 에만 `"cat": "misc"` 로 합칩니다 (`data/deadlines.json` 은 KIISE 전용 유지).
주간 GitHub Actions(`update-deadlines.yml`)가 자동으로 같은 작업을 수행합니다.

**한국·일본 개최 학회 갱신**: 새 학회의 한국·일본 개최가 발표되면
`data/korea_conferences.json` 의 `items` 에 항목을 추가(개최 국가는
`"country": "KR"` 또는 `"JP"`)한 뒤 `python3 scripts/build_korea.py` 를 실행하면
대시보드가 읽는 `docs/assets/korea.js` 가 다시 생성됩니다. (특별 관리 대상 학회
목록은 같은 파일의 `specialWatch` 에서 관리하며, 두 나라 공통으로 적용됩니다.)

한국·일본 개최 데이터는 GitHub Actions 두 개가 **반자동**으로 관리합니다. 스캔이
새 학회를 감지하면 후보 항목을 채운 PR 을 자동으로 열고, 관리자는 **PR 을
검토한 뒤 머지만 하면** 라이브 대시보드에 반영됩니다. (검증 안 된 정보가 곧바로
게시되지 않도록 PR 이 검수 게이트 역할을 합니다.)

| 워크플로 | 주기 | 하는 일 |
|---|---|---|
| `korea-scan.yml` | 매주 화요일(KST) | 연도별 URL 을 가진 15개 학회 공식 사이트를 스캔해 한국·일본 개최 신호(Seoul·COEX·Tokyo·Osaka 등)를 감지하면, 개최지·개최일·**국가**를 최선을 다해 추출한 후보 항목을 만들어 `korea-auto` 라벨 **PR** 을 자동 생성. 머지하면 반영, 오탐이면 PR 을 닫으면 됨(다시 제안되지 않음) |
| `korea-monthly-check.yml` | 매월 2일(KST) | 종료 후 60일 지난 학회를 `past` 로 보관하고, 특별 관리 13개 학회(단일 랜딩 페이지라 스캔이 어려운 AAAI·IJCAI 포함)의 개최지(한국/일본) 발표 확인 체크리스트를 `korea-check` 라벨 이슈로 생성 |

자동 감지된 항목은 개최지·개최일이 부정확할 수 있어 대시보드에서 **`🔎 검토중`**
배지로 표시됩니다. 머지 후 공식 정보를 최종 확인했으면 `data/korea_conferences.json`
에서 해당 항목의 `needsReview` 를 `false` 로 바꾸고 마감일을 채운 뒤 다시 빌드하세요.

**다른 연도 추가**: `data/` 폴더에 동일한 컬럼 형식의
`excellent_sw_conferences_2025.csv` 같은 파일을 넣고 위 스크립트를 다시 실행하면 됩니다.
빌드 스크립트가 `data/excellent_sw_conferences_*.csv` 를 모두 자동 병합하고, 각 학회의
연도는 `번호`(예: `2025-S-001`) 또는 파일명에서 추출합니다. 대시보드 상단 필터에
**연도 선택**이 자동으로 나타납니다.
